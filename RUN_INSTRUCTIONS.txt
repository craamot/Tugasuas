   $ flutter clean
   $ flutter pub get

4. Jalankan app sesuai pilihan:

   Untuk WEB:
   $ flutter run -d chrome

   Untuk ANDROID:
   $ flutter run

5. Tunggu proses compile selesai (1-2 menit)

6. Enjoy! App sudah jalan 🎉

⚠️ JIKA ADA ERROR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Error: "Plugin not found" atau "Compilation failed"
Solusi:
  $ flutter clean
  $ flutter pub get
  $ flutter pub upgrade
  $ flutter run

Error: "No connected devices"
Solusi:
  - Buka Android Emulator / Connect device
  - Atau gunakan: flutter run -d chrome

Error: "Cannot find device"
Solusi:
  $ flutter devices
  Lalu pilih device yang ada

Error: "gradle build failed"
Solusi:
  $ flutter clean
  $ flutter pub get
  $ flutter run

Error: Database/Login tidak bekerja
Solusi:
  Uninstall app dan install ulang:
  $ flutter clean
  $ flutter run
