## 🔧 KEY FUNCTIONS

### Register
```dart
bool success = await DatabaseHelper().registerUser(
  name: "User Name",
  email: "user@email.com",
  password: "password123",
);
```

### Login
```dart
User? user = await DatabaseHelper().loginUser(
  email: "user@email.com",
  password: "password123",
);
```

### Check Email
```dart
bool exists = await DatabaseHelper().isEmailExists("email@email.com");
```

## 🐛 TROUBLESHOOTING

### Problem: Files not found
**Solution:** Check file locations in FILE STRUCTURE section

### Problem: Database exception
**Solution:** Run `flutter clean && flutter pub get && flutter run`

### Problem: Login always fails
**Solution:** Check password - use `.trim()` to remove spaces

### Problem: Email validation fails
**Solution:** Verify regex pattern in db_helper.dart

### Problem: Duplicate email accepted
**Solution:** That's working correctly! Email must be unique
